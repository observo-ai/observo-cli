Observo CLI

Push CI test runs, coverage, and live test status to Observo.

Install (one-liner)

curl -fsSL https://cli.observoai.co/install | bash

Other channels

  • brew install observo-ai/tap/observo
  • npm install -g @observo-ai/cli
  • docker run --rm ghcr.io/observo-ai/observo-cli:latest --version
  • go install github.com/observo-ai/observo-cli@latest
